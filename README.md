# Smart Door Security System

This project is a password-based door security system built using Arduino Uno.

The user enters a password through a 4x4 keypad. If the password is correct, the door unlocks using a servo motor. If an incorrect password is entered, a buzzer alarm is triggered. The system can also use a PIR sensor to detect nearby motion.

## Components Used

- Arduino Uno
- 4x4 Keypad
- I2C LCD Display
- SG90 Servo Motor
- PIR Sensor
- Active Buzzer

## Working

1. User enters a password using the keypad.
2. LCD displays the entered status.
3. If the password is correct, the servo unlocks the door.
4. If the password is incorrect, the buzzer sounds.
5. The PIR sensor can detect motion near the door and trigger an alert.
